# Grade Curricular UFSC

Mapa interativo das disciplinas de cada fase, com linhas ligando os pré-requisitos.

## Cursos

- Engenharia Química — currículo 19911
- Engenharia Elétrica — currículo 20051

## Funcionalidades

- Marcar cada disciplina como aprovada, reprovada, cursando ou não cursada
- Disciplinas com pré-requisito pendente ficam bloqueadas e não podem ser marcadas
- Ao desmarcar um pré-requisito, as dependentes são desmarcadas em cadeia
- Destaque da cadeia de pré-requisitos e do que cada disciplina libera
- Lista de gargalos: disciplinas pendentes que mais travam o curso
- Pré-requisitos por carga horária (ex.: estágio, TCC)
- Escolha de optativas e projetos nos campos correspondentes
- Progresso salvo no navegador, separado por curso, com backup por copiar/colar

## Como usar

Abra o `index.html` no navegador, ou publique com GitHub Pages:
Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)`.

## Observações

As equivalências com códigos de currículos antigos não são consideradas. Os dados foram extraídos dos PDFs oficiais do currículo (CAGR/UFSC).
